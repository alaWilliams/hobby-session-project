## Hobby Session

Hobby Session is a full-stack web application that allows users to create, join, and manage local hobby events. The platform helps people organize sessions based on shared interests, set participation limits, and control visibility between public and private events.

The frontend, built with TypeScript and Vite, provides an intuitive and responsive user interface for managing sessions. The backend, powered by Node.js and Better-SQLite3, handles data storage, API requests, and secure session management. Together, they form a lightweight yet fully functional event management solution suitable for small community projects or personal learning.
